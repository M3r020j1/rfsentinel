RFSentinel — Flasher le dongle
LilyGO T-Dongle-S3 · Google Chrome ou Microsoft Edge · aucune installation

Cette page écrit le firmware dans la mémoire flash du dongle depuis le navigateur. Le moteur d'écriture est esptool-js, la version navigateur d'esptool maintenue par Espressif. Les images ne transitent par aucun serveur intermédiaire : elles viennent du dépôt ou de votre disque, et leur empreinte est vérifiée.

Vérifiez le modèle de la carte. RFSentinel écrit une table de partitions de 16 Mo. Une LilyGO T-Dongle-S3 de 8 Mo — même boîtier, même apparence — ne démarrera plus après l'écriture. La page lit la taille réelle de la mémoire avant d'écrire et refuse si elle n'est pas de 16 Mo.

Étape 2

Choisir le port du dongle

Brancher le dongle en USB-C, puis cliquer sur « Choisir le port ». Chrome liste les ports série accessibles ; sélectionner USB JTAG/serial debug unit. Si la liste est vide, maintenir le bouton BOOT (trou du fond) tout en branchant le dongle, puis relâcher.

Étape 3

Écrire le firmware

Le plan d’écriture est imposé par la page : puce esp32s3, flash dio / 80 MHz / 16 MB, écritures à 0x0, 0x8000 et 0x10000.
Après l'écriture

Premier démarrage

  1. Le dongle redémarre seul. L'écran affiche le logo RFSentinel puis la version.
  2. Sans réseau configuré, il émet le point d'accès RFSentinel-Setup (mot de passe 012345678).
  3. S'y connecter, puis ouvrir http://192.168.4.1.
  4. Première connexion avec admin / admin : le changement de mot de passe est imposé.
L'écriture du firmware ne touche pas à la partition storage : le journal des observations est conservé. « Effacer toute la flash » le supprime, ainsi que la configuration Wi-Fi.
